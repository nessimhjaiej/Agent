Run Locally (Windows PowerShell)
================================

For the full setup guide, read README.md first.

Option A) Start backend services with Docker Compose
----------------------------------------------------
From the project root:

docker compose up -d --build

Check backend service health:

curl.exe http://localhost:8000/health
curl.exe http://localhost:8001/health
curl.exe http://localhost:8002/health
curl.exe http://localhost:8003/health
curl.exe http://localhost:8004/health
curl.exe http://localhost:8005/health
curl.exe http://localhost:8006/health
curl.exe http://localhost:8007/health
curl.exe http://localhost:8080/v1/.well-known/ready

Option B) Start backend services locally with uvicorn
-----------------------------------------------------
Install Python dependencies first:

pip install -r requirements.txt

Start Weaviate:

docker compose up -d weaviate

Launch all local backend services:

powershell -ExecutionPolicy Bypass -File .\scripts\start-local-backend.ps1

Stop local backend services:

powershell -ExecutionPolicy Bypass -File .\scripts\stop-local-backend.ps1

Start frontend
--------------
Open a new terminal:

cd frontend
npm install
npm run dev

Open app
--------
http://localhost:5173

Stop Docker backend services
----------------------------
docker compose down
