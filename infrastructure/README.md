# Infrastructure

This folder contains environment and dependency setup assets for the project.

Current infrastructure dependencies represented here:

- `docker/` Docker and container orchestration notes
- `weaviate/` local Weaviate setup and schema bootstrap assets
- `supabase/` Supabase setup scripts and notes
- `openai/` OpenAI dependency notes

These are supporting systems required to run the application locally or in deployment environments. Application business logic remains in `services/` and `frontend/`.
